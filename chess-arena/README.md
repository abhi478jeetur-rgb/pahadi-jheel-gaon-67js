# ♞ शतरंज अखाड़ा — राजाओं का युद्ध (67js Game)

67js (WebGL2) से बना एक खेलने वाला 3D chess game — मेरे दिए हुए arena design के आधार पर:
दो राजा आमने-सामने अपने-अपने सिंहासन पर, बीच में किले की दीवारों से घिरा अखाड़ा,
और नीचे chess के मोहरे असली सैनिक बनकर खड़े हैं।

## ▶️ खेलो यहाँ

**https://abhi478jeetur-rgb.github.io/pahadi-jheel-gaon-67js/chess-arena/**

(laptop के browser में खोलो — वहाँ GPU से चलेगा, smooth और तेज़।)

## कैसे खेलें

- तुम **नीले राजा** हो। नीचे की तरफ़ तुम्हारी सेना है।
- अपने मोहरे पर क्लिक करो → हरी घेरियाँ उसके सही moves दिखाएँगी, लाल घेरी = मार सकते हो।
- जगह पर क्लिक करते ही सैनिक चल पड़ेगा।
- **मुकाबला (capture):** हमलावर सैनिक पास आकर हथियार से दो बार वार करेगा, दुश्मन
  हिलेगा और गिरकर हारेगा — बिल्कुल असली लड़ाई जैसा।
- लाल राजा (computer) ख़ुद सोचकर चाल चलता है। कठिनाई ऊपर के button से बदल सकते हो:
  आसान / मध्यम / कठिन।
- कैमरा: खींचकर घुमाओ, स्क्रॉल से ज़ूम। "दृश्य: राजा" button से अपने सिंहासन के
  पीछे से अखाड़ा देखो।
- शह लगने पर राजा के नीचे लाल घेरी आएगी और सिंहासन वाला राजा घबराकर हिलेगा।
  शह-मात पर हारा हुआ राजा का मोहरा गिर जाएगा।

## क्या-क्या है अंदर

- पूरा chess नियम: castling, en passant, प्यादा → रानी (promotion पर सच में रानी का
  मोहरा खड़ा होता है), शह / शह-मात / stalemate पहचान।
- Computer राजा: alpha-beta search वाला AI (कठिनाई के हिसाब से गहराई)।
- आवाज़: वार, कदम, शह और जीत की धुन — WebAudio से बनी, कोई file नहीं।
- Scene 67js recipe से बना है: 606 हिस्से — किला, 4 tower, 2 सिंहासन, 32 सैनिक-मोहरे
  (प्यादा = भाला-ढाल वाला सैनिक, घोड़ा = घुड़सवार, हाथी = बुर्ज़, ऊँट = बिशप,
  रानी और राजा ताज के साथ)।

## Files

- `index.html` — पूरा खेल (chess logic, AI, लड़ाई की animation, UI)
- `scene.json` — 67js scene recipe (`gen_game.py` से बनी)
- `build/` — 67js engine (repo के अंदर self-hosted, CDN पर निर्भर नहीं)
